# Durable Streaming Agent Sessions and Explicit Mock Boundary

All five domain agent workflows (Requirement Exploration, Ontology Copilot, Application Coding, Capability Smart Chat, and Data Ontology Reasoning) run as persistent, multi-turn `Agent Session` threads on `@earendil-works/pi-durable` (`SqliteStorage` with `pi_` table prefix across local SQLite and Cloudflare Durable Objects) and `@earendil-works/pi-ai`, streaming live `conversation.watch()` deltas, thinking traces, and multi-step tool executions (with `ontology-core` validation errors fed back for same-turn self-correction) to the browser over SSE, rendered with `@base-ui/react`-backed `beautifului.dev` agent primitives and `@assistant-ui/react`. Tools execute autonomously by default ("YOLO" mode, safeguarded by the `ontology-core` validator and workspace undo snapshots), reserving human-in-the-loop interactive cards (`ask_user`) strictly for collecting missing user inputs or resolving ambiguous business choices rather than permission-gating tool calls.

In normal operation, `agent-runtime` never falls back silently to deterministic regex mutations or hardcoded template strings when an LLM gateway is unconfigured, unreachable, or times out; instead, it surfaces actionable provider diagnostics with direct navigation to the LLM Center, isolating deterministic `faux`/mock responses strictly behind automated test suites and an explicit Demo/Mock mode flag.
